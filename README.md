# Thesis Supplementary Materials

This repository contains supplementary materials for my Princeton University senior thesis within the Department of Ecology and Evolutionary Biology, 
"Speaking the Language of the Spike: Predicting SARS-CoV-2 Viral Fitness Using Protein Language Models". Advised by Dr. Bryan T. Grenfell and Dr. Kaiyuan Sun.


## Contents

- `/code/` — Analysis scripts used to generate results in the thesis
- `/supplementary_figures/` — Additional figures and tables not included in the main text
