# Thesis Supplementary Materials

This repository contains supplementary materials for the senior thesis "Speaking the Language of the Spike: Predicting SARS-CoV-2 Viral Fitness Using Protein Language Models" 
by Emily M. Zhang, Department of Ecology and Evolutionary Biology, Princeton University, 2026.

## Contents
- `/code/` — Analysis scripts used to generate results in the thesis
- `/supplementary_figures/` — Additional figures and tables not included in the main text
